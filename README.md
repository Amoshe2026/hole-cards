# 底牌都市：铁人德扑

一个黑色叙事的德州扑克单页游戏。七张牌桌，七种结局，十四名有独立性格档案的 AI 对手。

**在线游玩**：https://amoshe2026.github.io/hole-cards/

## 玩法

从一间后巷木桌开始，靠一手一手的牌把资金做大，逐步解锁七张牌桌：

| 关 | 牌桌 | 买入 | 盲注 | 对手 |
|---|---|---|---|---|
| 1 | 后巷木桌 | 30 | 1 | 秃顶大汉 / 朋克小混混 |
| 2 | 街角酒馆 | 70 | 4 | 卡车司机 / 皮衣女郎 |
| 3 | 地下游戏厅 | 125 | 8 | 棒球帽游戏宅 / 泡泡糖女生 |
| 4 | 中国城茶馆 | 260 | 20 | 老掌柜 / 金链沉默男 |
| 5 | KTV豪华包厢 | 500 | 40 | 房地产销售 / 陪酒女 |
| 6 | 摩天大楼办公室 | 900 | 80 | 金融精英 / 女助理 |
| 7 | 私人游轮 | 1800 | 160 | 面具庄家 / 赌场老板 |

**一手一桌、逐手结算**：每一手上桌带入一个买入，牌局结束后按买入差额计入总资金。
总资金归零才会永久结束；买入打光但还有总资金，可以退回去打低级别的桌子。

最后一张牌桌有作弊庄家——他会在河牌动手脚，也会在摊牌时改写规则。
需要积累**破局值**（下大注、赢大底池）才能削弱他，否则打不穿。

## 对手模型

每名对手有六个参数，决定他如何行动：

| 参数 | 含义 |
|---|---|
| `tight` | 范围宽度——越高越少入池 |
| `bluff` | 诈唬频率 |
| `trap` | 慢打强牌（诱捕）的概率 |
| `call` | 跟注倾向 |
| `pressure` | 主动施压倾向与下注尺寸 |
| `tilt` | 情绪噪声——越高行为越随机 |

每个对手还配了各自的台词（弃牌 / 加注 / 诱捕 / 诈唬各有说法）和一句「读牌」提示。
